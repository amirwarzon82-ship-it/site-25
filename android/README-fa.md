# ساخت اپ اندروید دانش‌آموزان (APK)

این پروژه یک «پوسته‌ی اندرویدی» ساده است که صفحه‌ی دانش‌آموز سایت شما (`آدرس‌سایت/app`) را داخل یک اپ نمایش می‌دهد. بنابراین:
- هر تغییری در ظاهر یا امکانات سایت، **بدون نصب دوباره‌ی اپ** در اپ دیده می‌شود.
- اپ برای کار کردن **اینترنت لازم دارد**.
- روی هاست شما چیزی مثل جاوا لازم نیست؛ ساخت APK روی سرورهای GitHub انجام می‌شود.

## روش الف (پیشنهادی، بدون نصب هیچ برنامه‌ای)

1. در [github.com](https://github.com) یک حساب رایگان بسازید و وارد شوید.
2. دکمه‌ی **New repository** را بزنید، یک اسم بنویسید (مثلاً `class-app`) و **Create repository** را بزنید.
3. روی **uploading an existing file** کلیک کنید. سپس **همه‌ی فایل‌ها و پوشه‌های داخل این پوشه** را (نه خود پوشه را) بکشید و رها کنید؛ پوشه‌های `app` و `.github` هم باید باشند. بعد **Commit changes** را بزنید.
4. اگر پوشه‌ی `.github` (چون با نقطه شروع می‌شود و مخفی است) آپلود نشد: **Add file ← Create new file** را بزنید، در کادر اسم دقیقاً این را بنویسید: `.github/workflows/build-apk.yml` و محتوای زیر را در کادر بزرگ بچسبانید، بعد **Commit changes**:

```yaml
name: Build APK

on:
  push:
    branches: [main, master]
  workflow_dispatch:

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-java@v4
        with:
          distribution: temurin
          java-version: 17
      - uses: gradle/actions/setup-gradle@v4
        with:
          gradle-version: 8.9
      - name: Build debug APK
        run: gradle assembleDebug --no-daemon
      - uses: actions/upload-artifact@v4
        with:
          name: ClassApp-APK
          path: app/build/outputs/apk/debug/*.apk
          retention-days: 30
```

5. به تب **Actions** بروید. اگر ساخت خودکار شروع نشده بود، **Build APK** را انتخاب و **Run workflow** را بزنید.
6. حدود ۳ تا ۶ دقیقه صبر کنید تا تیک سبز بیاید. روی اجرای تمام‌شده کلیک کنید و پایین صفحه در بخش **Artifacts**، فایل **ClassApp-APK** را دانلود کنید.
7. فایل zip را باز کنید؛ داخلش یک فایل `.apk` است. آن را برای دانش‌آموزان بفرستید (تلگرام و غیره).
8. دانش‌آموز روی فایل بزند و اگر اندروید پرسید، اجازه‌ی **نصب از منابع ناشناس** را بدهد.

## روش ب (با Android Studio)

1. Android Studio را نصب کنید و **Open** ← همین پوشه را انتخاب کنید.
2. صبر کنید همگام‌سازی (Sync) تمام شود.
3. از منوی **Build ← Build Bundle(s) / APK(s) ← Build APK(s)** را بزنید.
4. فایل در `app/build/outputs/apk/debug/` ساخته می‌شود.

## اولین اجرا

دانش‌آموز اپ را باز می‌کند و **آدرس سایت** را یک بار وارد می‌کند؛ همان آدرسی که پنل استاد روی آن است، **بدون `/app`** (مثلاً `https://example.ir`). بعد با **نام کاربری و رمزی که استاد داده** وارد می‌شود. آدرس در گوشی ذخیره می‌شود. برای تغییر آدرس، از داخل اپ گزینه‌ی «تغییر آدرس سرور» یا از صفحه‌ی «اتصال برقرار نیست» استفاده کنید.

## آدرس سایت داخل اپ (اختیاری ولی پیشنهادی)
قبل از ساخت APK، فایل `app/src/main/res/values/strings.xml` را باز کنید و بین علامت‌های `<string name="default_server">` و `</string>` آدرس سایت را بنویسید (مثلاً `https://example.ir`). آن‌وقت دانش‌آموز مستقیم صفحه‌ی ورود را می‌بیند.

## اعلان‌ها
اپ نسخه‌ی ۲ برای اعلان‌ها اجازه می‌گیرد (اندروید ۱۳ به بالا). اعلان‌ها هنگام باز بودن اپ یا بلافاصله بعد از رفتن به پس‌زمینه می‌رسند.

## رفع مشکل

- **صفحه‌ی خالی یا «اتصال برقرار نیست»**: آدرس را بررسی کنید. اگر سایت با `http://` کار می‌کند همان را بنویسید و اگر `https://` است همان را. اینترنت گوشی را هم چک کنید.
- **«برنامه نصب نشد»**: نسخه‌ی قبلی اپ را حذف و دوباره نصب کنید.
- **آدرس را اشتباه زدم**: صفحه‌ی «اتصال برقرار نیست» ← «تغییر آدرس سرور»؛ یا اپ را حذف و دوباره نصب کنید.
- **ساخت در GitHub قرمز شد**: روی اجرای ناموفق کلیک کنید و متن خطا را برای پشتیبان بفرستید. معمولاً یکی از فایل‌ها کامل آپلود نشده است.
