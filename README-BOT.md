# 🤖 ربات تلگرام استاد + ساخت اپ از داخل تلگرام

طراحی و توسعه: امیرعلی ساقی · ۲۰۲۶

## ۱) فعال‌کردن ربات (۵ دقیقه)
1. در تلگرام به **@BotFather** بروید ← `/newbot` ← نام و یوزرنیم بدهید ← **توکن** را کپی کنید.
2. شناسه‌ی عددی تلگرام خودتان را از ربات **@userinfobot** بگیرید.
3. در Railway ← Variables این‌ها را اضافه کنید:

| متغیر | مقدار |
|---|---|
| `TELEGRAM_BOT_TOKEN` | توکن BotFather |
| `TELEGRAM_ADMIN_IDS` | شناسه‌ی ادمین‌ها با کاما، مثلاً `111111111,222222222` (استاد + هر کس دیگر) |
| `PUBLIC_URL` | (اختیاری) آدرس سایت، مثل `https://class.example.ir` — اگر خالی باشد از دامنه‌ی Railway خوانده می‌شود |

4. Deploy دوباره انجام شود. ربات خودش وب‌هوک را ثبت می‌کند و به ادمین‌ها پیام «فعال شد» می‌دهد. `/start` بزنید.

برای اضافه/حذف‌کردن ادمین فقط مقدار `TELEGRAM_ADMIN_IDS` را عوض کنید. هر کس غیر از این شناسه‌ها پیام بدهد فقط «دسترسی ندارید» می‌گیرد.

## ۲) ربات چه کارهایی می‌کند؟
داشبورد · تعویض کلاس · دانش‌آموزان (افزودن، رمز جدید، مسدود/آزاد، حذف) · حضور و غیاب امروز · نمرات (ساخت ستون، ورود نمره‌ی همه، جدول نهایی) · کوییزها (فعال/غیرفعال، نتایج، **تصحیح پاسخ‌های تشریحی همراه عکس برگه**) · اطلاعیه (ساخت، سنجاق، پنهان، حذف) · تکالیف (دیدن تحویل‌ها، نمره) · پیام‌ها (پاسخ) · فعالیت‌ها · پشتیبان (فایل کامل در همان چت) · تنظیمات (نمایش نمره/رتبه/…، تغییر رمز پنل وب).
همچنین هر ورود دانش‌آموز، پیام، تکلیف و پایان آزمون **همان لحظه** به ادمین‌ها اعلان می‌شود (از تنظیمات قابل خاموش‌کردن). دکمه‌ها رنگی‌اند (آبی/سبز/قرمز) — روی نسخه‌های جدید تلگرام (فوریه ۲۰۲۶ به بعد) نمایش داده می‌شود.

## ۳) ساخت اپ اندروید از داخل ربات
در ربات «📱 ساخت اپ اندروید» را بزنید ← دامنه را بفرستید ← (اختیاری) آیکون را به‌صورت **فایل** بفرستید ← «🚀 بساز و بفرست».
بعد از حدود ۴ تا ۸ دقیقه فایل **APK** در همان چت می‌آید.

ساخت روی GitHub Actions انجام می‌شود (روی Railway اندروید ساخته نمی‌شود)، پس یک‌بار این‌ها لازم است:
1. پروژه روی GitHub باشد (همان که به Railway وصل است).
2. در GitHub: Settings ← Developer settings ← Personal access tokens ← **Fine-grained** ← دسترسی `Contents: Read and write` و `Actions: Read and write` فقط برای همین مخزن.
3. در Railway این دو متغیر را بسازید: `GITHUB_TOKEN` (توکن بالا) و `GITHUB_REPO` (مثل `amirali/class-panel`). اگر شاخه‌ی اصلی `main` نیست `GITHUB_BRANCH` را هم بگذارید.

ربات آیکون را در شاخه‌ی جداگانه‌ی `apk-input` می‌گذارد (سایت Railway دوباره Deploy نمی‌شود).

## ۴) تازه‌ها در پنل
- ورود: متن‌ها دقیقاً وسط فیلد؛ طراحی جدید؛ دکمه‌ی «بازگشت به ورود استاد» در صفحه‌ی دانش‌آموز.
- خروج از حساب (استاد و دانش‌آموز) با پرسش «آیا می‌خواهید از حساب خود خارج شوید؟».
- زنگوله‌ی اعلان: عدد خوانده‌نشده‌ها دیگر بریده نمی‌شود.
- **سؤال تشریحی** در کوییز: دانش‌آموز تایپ می‌کند یا از برگه عکس می‌فرستد؛ استاد در «نتایج کوییز» تصحیح و نمره می‌دهد. نمره‌ی تشریحی‌ها به نمره‌ی آزمون می‌پیوندد.
- نمره‌ی کوییزها خودکار در «نمرات اصلی» و نمره‌ی نهایی حساب می‌شود (کوییزهای قدیمی هم خودکار وصل می‌شوند؛ آزمون‌های منتظر تصحیح تا تصحیح شدن حساب نمی‌شوند).
- عکس پروفایل: دانش‌آموز از «پروفایل»، استاد با کلیک روی نامش بالای صفحه (و روی عکس هر دانش‌آموز در پنجره‌ی او).

## ۵) اصلاح‌های امنیتی
- اگر `SESSION_SECRET` را نگذاشته باشید، یک کلید تصادفی خودکار ساخته می‌شود (کلید پیش‌فرض عمومی بود و جعل نشست ممکن می‌کرد).
- ورود استاد با رمز پیش‌فرض ممنوع شد؛ باید `ADMIN_PASS` را در Variables بگذارید.
- محدودیت تعداد تلاش ورود دیگر با جعل هدر `X-Forwarded-For` دور زده نمی‌شود.
